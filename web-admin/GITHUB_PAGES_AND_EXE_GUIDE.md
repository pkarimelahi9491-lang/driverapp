# راهنمای استقرار پنل وب روی GitHub Pages و خروجی EXE ویندوز

این پوشه (`/web-admin`) شامل نسخه اختصاصی و مستقل **پنل تحت وب و دسکتاپ مدیریت ناوگان و تسویه مالی هلدینگ آرمان انتخاب** است.

---

## ۱. نحوه آپلود و راه‌اندازی روی GitHub Pages (تست و هاستینگ رایگان وب)

برای اینکه این پنل وب را در گیت‌هاب قرار داده و لینک آنلاین آن را در مرورگر تست کنید:

1. وارد اکانت **GitHub** خود شوید و یک ریپازیتوری جدید (مثلاً به نام `fleet-admin-panel`) بسازید.
2. فایل‌های داخل پوشه `web-admin` (شامل `index.html`، `styles.css` و `app.js`) را در ریپازیتوری خود آپلود کنید.
3. در گیت‌هاب وارد بخش **Settings** ریپازیتوری شوید.
4. از منوی سمت چپ گزینه **Pages** را انتخاب کنید.
5. در بخش **Build and deployment**:
   - Source را روی **Deploy from a branch** بگذارید.
   - Branch را روی **main** و شاخه `/ (root)` تنظیم کرده و دکمه **Save** را بزنید.
6. پس از ۱ دقیقه، لینک اختصاصی وب شما به این صورت فعال می‌شود:
   `https://<your-username>.github.io/fleet-admin-panel/`

---

## ۲. نحوه تولید فایل اجرایی ویندوز (EXE)

شما می‌توانید به دو روش بسیار ساده از این سورس، خروجی نرم‌افزار دسکتاپ ویندوز (`.exe`) بگیرید:

### روش اول: تولید EXE بدون نیاز به نصب هیچ ابزار جانبی (با Nativefier در ۱ ثانیه)
اگر Node.js روی سیستم شما نصب است، کافیست در ترمینال یا CMD دستور زیر را اجرا کنید:
```bash
npx nativefier --name "مدیریت ناوگان آرمان انتخاب" --width 1280 --height 850 --platform windows "https://<your-github-username>.github.io/fleet-admin-panel/"
```
یک پوشه حاوی فایل `مدیریت ناوگان آرمان انتخاب.exe` مستقیماً تولید می‌شود!

### روش دوم: خروجی با Electron و Electron-Builder (آفلاین و لوکال)
1. ترمینال را در پوشه `web-admin` باز کنید.
2. وابستگی‌ها را با دستور زیر نصب کنید:
   ```bash
   npm install
   ```
3. برای تست و اجرای نرم‌افزار دسکتاپ:
   ```bash
   npm start
   ```
4. برای تولید نهایی فایل **EXE پورتابل**:
   ```bash
   npm run dist
   ```
   فایل نصبی و قابل‌حمل ویندوز در پوشه `dist/` با پسوند `.exe` آماده خواهد بود.

## ۳. تفکیک نسخه راننده و پنل ادمین در اپلیکیشن اندروید (Mobile App)

در اپلیکیشن اندروید نیز دو قابلیت اساسی افزوده شد:
1. **قفل اختصاصی راننده (Driver-Locked Mode):** با زدن آیکون قفل بالای صفحه، برنامه کاملاً در نسخه راننده قفل می‌شود و دسترسی به منوهای مدیریت، مسیرها و حسابداری ناپدید می‌گردد.
2. **ورود امن با رمز عبور سرپرست (Admin PIN):** برای بازگشت به پنل مدیریت یا حسابداری، رمز عبور مدیر هلدینگ (پیش‌فرض: `۱۴۰۳`) الزامی است تا رانندگان به هیچ عنوان دسترسی به اطلاعات مالی و تغییر نرخ‌ها نداشته باشند.
