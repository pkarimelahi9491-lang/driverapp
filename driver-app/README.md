# 🚗 اپ رانندگان — هلدینگ آرمان انتخاب

اپلیکیشن رانندگان برای ثبت سفرها، مشاهده کارکرد و درآمد روزانه و ماهانه.

## ✨ امکانات

- 🔐 **ورود با نام کاربری و رمز عبور**
- 📝 **ثبت سفر جدید** با انتخاب مبدأ و مقصد از لیست
- 💰 **محاسبه خودکار نرخ** بر اساس کد مسیر
- 📅 **تقویم شمسی** برای مشاهده سوابق
- 📊 **آمار سفرها و درآمد** روزانه و ماهانه
- ✅ **ثبت نهایی کارکرد روز** با تأیید نهایی
- 💾 **ذخیره‌سازی آفلاین** با localStorage
- 🎨 **طراحی مدرن** با Glass Morphism

## 🖥️ اجرا به صورت وب (مرورگر)

فایل `index.html` را در مرورگر باز کنید:
```
ساده‌ترین راه — فقط فایل HTML را باز کنید!
```

## 📦 ساخت فایل EXE (ویندوز)

### پیش‌نیازها:
- Node.js نسخه 18 یا بالاتر
- npm

### مراحل:
```bash
cd driver-app

# 1. نصب وابستگی‌ها
npm install

# 2. ساخت فایل EXE
npm run build-win

# یا از فایل bat استفاده کنید:
build-exe.bat
```

فایل نصبی در پوشه `release/` ایجاد می‌شود.

## 📱 نحوه استفاده

1. **ورود:** نام کاربری (مثلاً ar-101) و رمز (123456) را وارد کنید
2. **ثبت سفر:** دکمه + را بزنید، مبدأ و مقصد را انتخاب کنید
3. **مشاهده نرخ:** سیستم خودکار کد مسیر و نرخ را پیدا می‌کند
4. **تأیید سفر:** دکمه "تأیید و ثبت سفر" را بزنید
5. **ثبت نهایی:** در پایان روز، "ثبت نهایی کارکرد" را بزنید
6. **تقویم:** برای مشاهده سوابق روزهای قبل

## 🗂️ ساختار فایل‌ها

